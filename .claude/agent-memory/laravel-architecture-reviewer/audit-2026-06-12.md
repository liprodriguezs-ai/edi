**Audit date:** 2026-06-12
**Scope:** 803df3a..HEAD — Collections, Board, Announcements, Projects, Treasury, Configuration, User hotspots + new Collections tests

**Key findings:**
1. CORRECTNESS: UserController::updatePassword (line 305) validates only `password` (old); `new_password` is unvalidated — could be null. `Hash::make(null)` produces empty hash; no min length, no confirmed check.
2. SECURITY: AnnouncementController::uploadMedia accepts any file type (no mimes/mimetypes rule) — arbitrary file upload.
3. DEBT: ConfigurationController extends `Illuminate\Routing\Controller` instead of `QCH\Core\Http\Controllers\Controller` — breaks pattern, must roll its own auth (`requireAbility`). Intentional but violates convention.
4. PERF: cancelBatch in ChargeGenerationService (line 213) uses per-unit `recomputeUnitAggregate()` in a foreach loop. activateBatch correctly uses the batch `recomputeUnitAggregates()`. Large clusters with 500+ units in a batch will trigger N+1 unit recompute queries on cancellation.
5. SECURITY: TenantIsolationTest only covers Unit, BankAccount, CommunityProject — does NOT cover Charge or Payment (the most financially sensitive resources). Cross-tenant payment leak remains untested.
6. CORRECTNESS: UserController::afterUpdate role-guard condition is logically inverted (fires 403 to superAdmin when changing NON-owner to NON-owner, not when protecting owner role from non-superadmin).
7. DEBT: UserController has two password change methods (resetPassword + updatePassword) with different validation and overlapping purpose.
8. DEBT: Dead commented-out code blocks in UserController (update_password, cash_register_session, etc.)

**Already fixed (do not re-report):** active-membership end_date gates, upload MIME caps, env() for Stripe, N+1 in charge-status recompute (batch path), synchronous FCM, payment concurrency invariants.

**Why:** Future auditors should not re-discover fixed issues or miss patterns established here.
**How to apply:** When reviewing UserController, ConfigurationController, or Collections services — check these patterns first.
